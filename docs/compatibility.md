# 兼容性与验证边界

更新日期：2026-10-02。路径及账户字段核对基于 Claude Code 2.1.287；它们属于内部实现，后续版本可能改变。

本项目提供 Go 单文件 CLI，命令为 `login NAME`、`save NAME`、`list`、`use NAME`、`remove NAME` 和 `recover`。先退出 Claude Code，再切换账户，最后在原项目目录运行 `claude --continue` 或 `claude --resume`。正在运行的进程可能缓存身份，因此检测到相关进程时拒绝切换。

## 状态保存范围

只保存和恢复账户字段 `claudeAiOauth`、`trustedDeviceToken`、`oauthAccount`。现有共享配置目录、hooks、项目记录和会话内容应保留。账户快照会包含敏感登录材料，不应提交到版本库或公开分享。

不使用代理、后台刷新、自动轮换或环境变量修改。Claude Code 负责官方登录和凭据刷新。闲置快照仍可能过期、被服务器撤销或因刷新令牌轮换失效，必要时需要重新登录。

保留环境变量意味着原有 `ANTHROPIC_API_KEY`、`ANTHROPIC_AUTH_TOKEN`、自定义 API 地址等覆盖设置也继续存在；它们可能使 Claude 使用供应商凭据而不是所选订阅账户。应检查现有覆盖配置，但本工具不自动清除。

同一账户在多个独立凭据副本中并发刷新可能令旧快照失效。切换流程应先停止 Claude，保存当前最新身份，再使用目标身份并重新启动。`recover` 用于恢复本地切换状态，不能撤销服务器端凭据撤销或账户限制。

## 平台与验证状态

| 平台 | 存储方式 | 自动化验证 | 真实账户验证 |
| --- | --- | --- | --- |
| Windows | 官方凭据文件；工具状态目录使用当前用户 ACL | 原生 CI 测试、静态检查、构建通过；本机测试通过 | 未执行 |
| macOS | 现有 Keychain 或文件回退；保留现有后端 | 原生 CI 测试、静态检查、构建通过；包含隔离 Keychain 读写和恢复 | 未执行 |
| Linux | 官方凭据文件；工具目录 0700、文件 0600 | 原生 CI 测试、静态检查、构建通过 | 未执行 |

测试使用临时目录及虚构凭据，覆盖账号切换、原配置与聊天文件保留、刷新后的凭据保存、写入失败、中断恢复、损坏数据拒绝和登录取消清理。macOS 测试使用新建的隔离钥匙串和唯一的测试服务名，不读取真实 Claude Keychain 项目。原生测试验证数据写入后、权限恢复前中断的恢复路径，并核对官方 `security` 回读和原访问规则；不同现有登录钥匙串的存储策略仍需实机验证。三系统及六种构建的通过记录见 [CI](https://github.com/harveyxiacn/clauflip/actions/runs/36970467977)。

源码构建需要 Go 1.26 或更新版本。macOS 构建还需要 Xcode Command Line Tools 和启用 CGO，以调用系统 Security.framework；生成的命令本身不需要安装 Go。CI 为三个系统分别构建 amd64、arm64 二进制；交叉构建不代表每种 CPU 均经过运行测试。

macOS 访问已有 Keychain 项目可能需要解锁；凭据更新需要保留原访问规则，系统可能要求所有者确认或输入钥匙串密码。自动化测试使用虚构钥匙串及预先授权的测试程序，验证获得授权后的读写路径，不代替真实桌面授权窗口验证。拒绝授权或中断时，按恢复记录提示处理。配置路径含用户自建符号链接时拒绝修改；macOS 系统自带 `/var`、`/tmp` 别名例外。

尚未执行真实多账户浏览器授权、线上令牌刷新及跨账户会话恢复测试。自动化测试通过不等于这些交互已经验证。

普通切换失败时恢复之前的账户；中断留下恢复记录时，按提示退出 Claude 后运行 `clauflip recover`。同一账号重新登录取得新凭据后若启用中断，恢复操作会继续启用新凭据，避免后续操作将其覆盖为旧凭据。

macOS 修改 Keychain 内容前，会把原访问分区规则、具体项目引用及前后内容摘要保存到私有恢复记录。中断后先恢复原访问规则，再处理账号恢复；若项目已被替换或凭据已被外部修改，则停止操作。权限恢复记录不包含登录令牌；账号快照及账号切换恢复记录仍包含凭据，受同样的本地文件权限保护。

## 无法作出的保证

Claude Code 的内部凭据字段、文件路径、Keychain 服务名及身份缓存不是稳定公共接口，版本更新可能改变它们。遇到不认识的状态应停止修改并提示，不能推断新字段属于哪个账户。

保留会话文件只保证本地内容仍在，不能保证每个会话都能跨身份恢复。账户级组织策略、权限、服务端连接器授权和订阅能力随身份变化，无法靠复制本地字段保留。部分工具或 MCP 服务也可能要求针对新身份重新授权。

本工具没有得到 Anthropic 官方背书，不能保证账户永不失效或不会受到服务政策限制。参考项目的星数与维护频率不能代替真实兼容性验证；已知上游问题和筛选结论见 [开源参考与取舍](references.md)。
