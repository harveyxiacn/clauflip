# 兼容性与验证边界

更新日期：2026-10-02。

本项目提供 Go 单文件 CLI，命令为 `login NAME`、`save NAME`、`list`、`use NAME`、`remove NAME` 和 `recover`。切换后退出并重新启动 Claude Code，再使用其恢复会话能力继续原会话。正在运行的进程可能缓存身份；切换磁盘状态不代表它立即使用新账户。

## 状态保存范围

只保存和恢复账户字段 `claudeAiOauth`、`trustedDeviceToken`、`oauthAccount`。现有共享配置目录、hooks、项目记录和会话内容应保留。账户快照会包含敏感登录材料，不应提交到版本库或公开分享。

不使用代理、后台刷新、自动轮换或环境变量修改。Claude Code 负责官方登录和凭据刷新。闲置快照仍可能过期、被服务器撤销或因刷新令牌轮换失效，必要时需要重新登录。

保留环境变量意味着原有 `ANTHROPIC_API_KEY`、`ANTHROPIC_AUTH_TOKEN`、自定义 API 地址等覆盖设置也继续存在；它们可能使 Claude 使用供应商凭据而不是所选订阅账户。应检查现有覆盖配置，但本工具不自动清除。

同一账户在多个独立凭据副本中并发刷新可能令旧快照失效。切换流程应先停止 Claude，保存当前最新身份，再使用目标身份并重新启动。`recover` 用于恢复本地切换状态，不能撤销服务器端凭据撤销或账户限制。

## 平台与验证状态

| 平台 | 预期支持 | 自动化验证 | 真实账户验证 |
| --- | --- | --- | --- |
| Windows | 文件凭据存储；保留同一配置目录 | 待主实现更新：构建、隔离目录测试和平台 CI | 未执行 |
| macOS | 系统 Keychain 账户凭据与本地身份元数据 | 待主实现更新：构建、Keychain 测试替身和平台 CI | 未执行 |
| Linux | 文件凭据存储；保留同一配置目录 | 待主实现更新：构建、隔离目录测试和平台 CI | 未执行 |

上表中的“预期支持”是实现目标，不等于三个平台均已实机验证。交叉编译只能证明能生成目标二进制；测试替身不能证明真实 Keychain 权限和访问行为正确。实际通过的命令及 CI 结果应由主实现完成后补充。

没有授权或执行真实多账户登录、浏览器授权、线上令牌刷新和跨账户会话恢复测试。自动化验证应只使用临时目录、模拟凭据和必要的系统存储替身，不读取或改写用户真实登录状态。

## 无法作出的保证

Claude Code 的内部凭据字段、文件路径、Keychain 服务名及身份缓存不是稳定公共接口，版本更新可能改变它们。遇到不认识的状态应停止修改并提示，不能推断新字段属于哪个账户。

保留会话文件只保证本地内容仍在，不能保证每个会话都能跨身份恢复。账户级组织策略、权限、服务端连接器授权和订阅能力随身份变化，无法靠复制本地字段保留。部分工具或 MCP 服务也可能要求针对新身份重新授权。

本工具没有得到 Anthropic 官方背书，不能保证账户永不失效或不会受到服务政策限制。参考项目的星数与维护频率不能代替真实兼容性验证；已知上游问题和筛选结论见 [开源参考与取舍](references.md)。
